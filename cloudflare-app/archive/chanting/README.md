# Archived chanting clips

The retired 2-, 5-, and 10-minute clips and their original `metadata.json`
remain here for reference. They are outside Vite's `public` directory, so
they are not copied into `dist` or uploaded by Cloudflare Pages deployment.

The app's Skip / Play controls use `default-intro.mp3` and `default-outro.mp3`
from `public/audio/chanting/`. Keep only recordings used by the app in
`public/audio/`; putting these archived clips back there would deploy them again.

The deployed `public/audio/metadata.json` retains empty legacy chanting lists
for compatibility with the current metadata reader. The original clip catalog
is preserved here unchanged.
